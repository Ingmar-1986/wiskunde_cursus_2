De afgeleide functie

In het vorige hoofdstuk bekeken we de afgeleide in één punt: het afgeleid getal f'(a). Nu laten we het punt variëren. Zo ontstaat een nieuwe functie, de afgeleide functie f', die in elk punt beschrijft hoe snel de oorspronkelijke functie verandert. We frissen ook op hoe je de eerste en tweede afgeleide van veeltermfuncties berekent. Die technieken vormen de basis voor het functieonderzoek in het volgende hoofdstuk en voor de nieuwe afleidingstechnieken die later in deze module volgen.

1
Waarom leer je dit?

In het vorige hoofdstuk keken we naar de verandering van een functie in één specifiek punt.

Als bijvoorbeeld

\[ f'(3)=5, \]

dan weten we hoe \(f\) verandert bij \(x=3\).

Maar meestal willen we niet alleen weten wat er in één punt gebeurt. We willen kunnen onderzoeken hoe de verandering zelf varieert wanneer \(x\) verandert.

Daarom stellen we voor elk geschikt punt dezelfde vraag:

\[ \boxed {\text {hoe snel verandert }f\text { hier?}} \]

Het antwoord hangt af van \(x\) en vormt dus opnieuw een functie.

Die nieuwe functie noemen we de afgeleide functie.

\[ \boxed { f \longrightarrow f' } \]

De oorspronkelijke functie \(f\) beschrijft de grootheid.

De afgeleide functie \(f'\) beschrijft hoe die grootheid verandert.

Later zullen we precies die informatie gebruiken om grafieken systematisch te onderzoeken.

2
Van afgeleid getal naar afgeleide functie

2.1

Eén punt: het afgeleid getal

Voor een vaste waarde \(a\) is

\[ f'(a) \]

een getal.

Het beschrijft de ogenblikkelijke verandering van \(f\) bij \(x=a\).

Meetkundig is het de richtingscoëfficiënt van de raaklijn aan de grafiek van \(f\) in

\[ P(a,f(a)). \]

Bijvoorbeeld:

\[ f'(2)=4 \]

betekent dat de raaklijn bij \(x=2\) richtingscoëfficiënt \(4\) heeft.

2.2

Alle punten: de afgeleide functie

We kunnen het afgeleid getal niet alleen bij \(x=2\) bepalen, maar bij elke waarde van \(x\) waarvoor de functie afleidbaar is.

Zo ontstaat een nieuwe functie.

DEFINITIE — Afgeleide functie

De afgeleide functie van een functie \(f\) is de functie

\[ f' \]

die aan elke waarde \(x\) het afgeleid getal van \(f\) in dat punt toekent.

Dus:

\[ \boxed { x\longmapsto f'(x) } \]

waarbij \(f'(x)\) de ogenblikkelijke verandering van \(f\) bij \(x\) beschrijft.

Het onderscheid is belangrijk:

\[ \boxed {f'(a)} \qquad \text {is een getal,} \]

terwijl

\[ \boxed {f'} \qquad \text {een functie is.} \]

Voorbeeld 1

Beschouw

\[ f(x)=x^2. \]

De afgeleide functie is

\[ f'(x)=2x. \]

Daaruit kunnen we verschillende afgeleide getallen bepalen:

\[ f'(1)=2, \qquad f'(3)=6, \qquad f'(-2)=-4. \]

De functie

\[ f'(x)=2x \]

geeft dus voor elk punt onmiddellijk de richtingscoëfficiënt van de raaklijn aan de grafiek van \(f\).

Oefening 1

— Afgeleid getal of afgeleide functie?

BESS

Gegeven is

\[ f'(x)=3x^2-4. \]

Is \(f'\) een getal of een functie?

Een getal Een functie

Bereken

\[ f'(2)=\answer {8}. \]

Wat stelt \(f'(2)\) meetkundig voor?

De \(y\)-coördinaat van een punt op de grafiek van \(f\). De richtingscoëfficiënt van de raaklijn aan de grafiek van \(f\) bij \(x=2\). De gemiddelde verandering van \(f\) over \([0,2]\).

3
Basisregels voor veeltermfuncties

We frissen nu de afleidingsregels op die nodig zijn om veeltermfuncties af te leiden.

Het doel is niet om de volledige theorie opnieuw op te bouwen, maar om deze regels opnieuw vlot beschikbaar te maken.

3.1

De afgeleide van een constante functie

Beschouw een constante functie

\[ f(x)=c. \]

De grafiek is een horizontale rechte.

De richtingscoëfficiënt is overal nul.

Daarom geldt:

EIGENSCHAP — Constante functie

Voor elke constante \(c\):

\[ \boxed { (c)'=0 } \]

of equivalent:

\[ f(x)=c \quad \Longrightarrow \quad f'(x)=0. \]

Voorbeeld 2

Als

\[ f(x)=7, \]

dan is

\[ f'(x)=0. \]

Ook voor

\[ g(x)=-13 \]

geldt

\[ g'(x)=0. \]

3.2

De machtsregel

Een van de belangrijkste basisregels is de machtsregel.

EIGENSCHAP — Machtsregel

Voor een positieve gehele exponent \(n\) geldt:

\[ \boxed { (x^n)'=n x^{n-1} } \]

Je kunt de regel onthouden als:

\[ \boxed { \text {exponent naar voren} \quad \text {en}\quad \text {exponent één verminderen}. } \]

Voorbeeld 3

\[ f(x)=x^5 \]

geeft

\[ f'(x)=5x^4. \]

Voor

\[ g(x)=x^3 \]

vinden we

\[ g'(x)=3x^2. \]

En voor

\[ h(x)=x \]

kunnen we schrijven

\[ h(x)=x^1, \]

zodat

\[ h'(x)=1x^0=1. \]

OPMERKING

Bij

\[ x^1 \]

wordt de exponent na afleiden nul.

Omdat

\[ x^0=1, \]

geldt dus

\[ (x)'=1. \]

3.3

Een constante factor

Een constante factor blijft bij het afleiden behouden.

EIGENSCHAP — Constante-factorregel

Als \(c\) een constante is, dan:

\[ \boxed { (c\,f(x))'=c\,f'(x) } \]

In het bijzonder:

\[ (ax^n)'=a n x^{n-1}. \]

Voorbeeld 4

Voor

\[ f(x)=4x^5 \]

geldt

\[ f'(x)=4\cdot 5x^4=20x^4. \]

Voor

\[ g(x)=-3x^2 \]

geldt

\[ g'(x)=-3\cdot 2x=-6x. \]

3.4

Som- en verschilregel

Bij een som of verschil mogen we term per term afleiden.

EIGENSCHAP — Som- en verschilregel

Voor afleidbare functies \(f\) en \(g\) geldt:

\[ \boxed { (f+g)'=f'+g' } \]

en

\[ \boxed { (f-g)'=f'-g'. } \]

Daardoor kunnen we een veelterm eenvoudig term per term afleiden.

Voorbeeld 5

Gegeven:

\[ f(x)=3x^4-5x^2+7x-9. \]

We leiden elke term afzonderlijk af:

\[ f'(x) = 12x^3-10x+7. \]

De constante term \(-9\) verdwijnt omdat

\[ (-9)'=0. \]

4
Veeltermfuncties afleiden

4.1

Term per term

Voor een veeltermfunctie

\[ f(x) = a_nx^n+a_{n-1}x^{n-1}+\cdots +a_1x+a_0 \]

kunnen we elke term afzonderlijk afleiden.

We krijgen:

\[ \boxed { f'(x) = na_nx^{n-1} +(n-1)a_{n-1}x^{n-2} +\cdots +a_1. } \]

Voorbeeld 6

Bepaal de afgeleide van

\[ f(x) = -2x^5+3x^4-7x^2+6. \]

We leiden term per term af:

\[ (-2x^5)'=-10x^4, \]
\[ (3x^4)'=12x^3, \]
\[ (-7x^2)'=-14x, \]

en

\[ (6)'=0. \]

Dus:

\[ \boxed { f'(x) = -10x^4+12x^3-14x. } \]

Oefening 2

— Veeltermfuncties afleiden

BESS

Bepaal telkens de afgeleide functie.

\[ f(x)=5x^4-3x^2+8 \]
\[ f'(x)=\answer {20x^3-6x}. \]
\[ g(x)=-2x^3+7x-4 \]
\[ g'(x)=\answer {-6x^2+7}. \]
\[ h(x)=\frac {1}{2}x^6-4x^3+x \]
\[ h'(x)=\answer {3x^5-12x^2+1}. \]

4.2

Vereenvoudig wanneer dat nuttig is

Een functie staat niet altijd onmiddellijk in de handigste vorm.

Bij veeltermfuncties kan het nuttig zijn om eerst haakjes weg te werken of gelijksoortige termen samen te nemen.

Voorbeeld 7

Gegeven:

\[ f(x)=2x(x^2-3x+4). \]

Omdat dit een product van veeltermen is, kunnen we eerst uitwerken:

\[ f(x)=2x^3-6x^2+8x. \]

Nu leiden we term per term af:

\[ \boxed { f'(x)=6x^2-12x+8. } \]

OPMERKING

Later leren we regels waarmee we producten van functies rechtstreeks kunnen afleiden.

Voor deze opfrissing van veeltermfuncties is eerst uitwerken vaak voldoende.

Oefening 3

— Eerst vereenvoudigen

UESS

Gegeven:

\[ f(x)=(x+2)(x^2-3x+1). \]

Werk eerst uit en bepaal daarna \(f'(x)\).

Eerst:

\[ f(x) = x^3-x^2-5x+2. \]

Daarom:

\[ \boxed { f'(x)=3x^2-2x-5. } \]

5
Controleer je afgeleide

5.1

De graad daalt met één

Bij een niet-constante veeltermfunctie daalt de graad na afleiden met één.

Bijvoorbeeld:

\[ f(x)=4x^5-2x^3+x \]

heeft graad \(5\).

De afgeleide

\[ f'(x)=20x^4-6x^2+1 \]

heeft graad \(4\).

Dit geeft een snelle controle.

5.2

Constante termen verdwijnen

Een constante term heeft geen invloed op de verandering van een functie.

Daarom verdwijnt hij bij het afleiden.

Als

\[ f(x)=3x^2+5 \]

en

\[ g(x)=3x^2-100, \]

dan geldt voor beide:

\[ f'(x)=g'(x)=6x. \]

De grafieken liggen verticaal verschoven ten opzichte van elkaar, maar hebben bij dezelfde \(x\) dezelfde helling.

Oefening 4

— Welke afgeleide kan kloppen?

UESS

Gegeven is

\[ f(x)=2x^4-5x^2+7. \]

Welke uitdrukking kan de afgeleide zijn?

\(8x^4-10x\) \(8x^3-10x\) \(8x^3-10x+7\) \(2x^3-5x\)

Leg je keuze uit aan de hand van minstens twee afleidingsregels.

6
De eerste en tweede afgeleide

6.1

De afgeleide opnieuw afleiden

Omdat \(f'\) zelf een functie is, kunnen we — wanneer dit mogelijk is — ook \(f'\) opnieuw afleiden.

Zo ontstaat de tweede afgeleide.

DEFINITIE — Tweede afgeleide

De afgeleide van de afgeleide functie noemen we de tweede afgeleide van \(f\).

We noteren:

\[ \boxed { f''(x)=(f'(x))'. } \]

Voorbeeld 8

Gegeven:

\[ f(x)=2x^4-3x^3+5x. \]

De eerste afgeleide is

\[ f'(x)=8x^3-9x^2+5. \]

We leiden opnieuw af:

\[ f''(x)=24x^2-18x. \]

Dus:

\[ \boxed { f'(x)=8x^3-9x^2+5 } \]

en

\[ \boxed { f''(x)=24x^2-18x. } \]

Oefening 5

— Eerste en tweede afgeleide

BESS

Gegeven:

\[ f(x)=x^5-4x^3+6x^2-2. \]

Bepaal \(f'\) en \(f''\).

\[ f'(x) = \answer {5x^4-12x^2+12x}. \]
\[ f''(x) = \answer {20x^3-24x+12}. \]

7
Wat vertellen \(f'\) en \(f''\)?

7.1

De eerste afgeleide beschrijft verandering

De eerste afgeleide

\[ f'(x) \]

vertelt hoe \(f\) ogenblikkelijk verandert.

Zo geldt lokaal:

\[ f'(x)>0 \]

wanneer de grafiek in dat punt een positieve helling heeft,

\[ f'(x)<0 \]

wanneer de helling negatief is,

en

\[ f'(x)=0 \]

wanneer de raaklijn horizontaal is.

We zullen in het volgende hoofdstuk onderzoeken hoe het teken van \(f'\) over volledige intervallen gebruikt wordt om stijgen, dalen en extrema te analyseren.

7.2

De tweede afgeleide beschrijft de verandering van de verandering

De tweede afgeleide

\[ f''(x) \]

beschrijft hoe \(f'(x)\) verandert.

Je kunt dit lezen als:

\[ \boxed { f \quad \xrightarrow {\text {afleiden}}\quad f' \quad \xrightarrow {\text {afleiden}}\quad f''. } \]

Daarbij beschrijft:

\[ f \]

de oorspronkelijke grootheid,

\[ f' \]

de verandering van die grootheid,

en

\[ f'' \]

hoe die verandering zelf verandert.

Voorbeeld 9 — Beweging

Stel dat

\[ s(t) \]

de positie van een bewegend voorwerp beschrijft in meter, met \(t\) in seconde.

Dan is

\[ s'(t) \]

de ogenblikkelijke snelheid in

\[ \mathrm {m/s}, \]

en

\[ s''(t) \]

de ogenblikkelijke versnelling in

\[ \mathrm {m/s^2}. \]

Hier zien we zeer concreet het verschil tussen een functie, haar eerste afgeleide en haar tweede afgeleide.

Oefening 6

— Beweging

UESS

De positie van een voorwerp wordt gegeven door

\[ s(t)=t^3-6t^2+9t \]

met \(s\) in meter en \(t\) in seconde.

Bepaal de snelheidsfunctie.

\[ v(t)=s'(t)=\answer {3t^2-12t+9}. \]

Bepaal de versnellingsfunctie.

\[ a(t)=s''(t)=\answer {6t-12}. \]

Bereken de snelheid bij \(t=2\).

\[ v(2)=\answer {-3}. \]

Welke eenheid hoort bij \(v(2)\)?

\(\mathrm {m}\) \(\mathrm {m/s}\) \(\mathrm {m/s^2}\)

Bereken de versnelling bij \(t=2\).

\[ a(2)=\answer {0}. \]

8
Veelgemaakte denkfouten

8.1

\(f'(x)\) en \(f(x)\) verwarren

De uitdrukking

\[ f(x) \]

geeft een functiewaarde.

De uitdrukking

\[ f'(x) \]

geeft de ogenblikkelijke verandering van die functiewaarde.

Het zijn verschillende functies en ze hebben in het algemeen verschillende waarden.

8.2

Een constante niet laten verdwijnen

Bijvoorbeeld:

\[ f(x)=4x^3+7. \]

Dan is niet

\[ f'(x)=12x^2+7, \]

maar

\[ \boxed { f'(x)=12x^2. } \]

De afgeleide van de constante \(7\) is nul.

8.3

De exponent vergeten te verminderen

Uit

\[ (x^5)'=5x^4 \]

volgt niet alleen dat de exponent als factor vooraan komt.

De exponent moet ook met één verminderen.

8.4

\(f''\) verwarren met \((f')^2\)

De notatie

\[ f''(x) \]

betekent:

\[ (f'(x))'. \]

Ze betekent niet:

\[ (f'(x))^2. \]

9
Kun je de ideeën verbinden?

Oefening 7

— Van functie naar verandering

UESS

Gegeven is

\[ f(x)=x^3-3x^2-9x+5. \]

Bepaal de eerste afgeleide.

\[ f'(x)=\answer {3x^2-6x-9}. \]

Bepaal de tweede afgeleide.

\[ f''(x)=\answer {6x-6}. \]

Bereken

\[ f'(0)=\answer {-9}. \]

Wat betekent dit meetkundig?

De grafiek gaat door \((0,-9)\). De raaklijn aan de grafiek bij \(x=0\) heeft richtingscoëfficiënt \(-9\). De functie heeft noodzakelijk een minimum bij \(x=0\).

Een leerling beweert:

“Omdat \(f'(0)<0\), is \(f\) overal dalend.”

Is dat besluit correct?

Ja, want een negatieve afgeleide betekent altijd dat een functie over haar volledige domein daalt. Nee. \(f'(0)<0\) geeft alleen informatie over de verandering bij \(x=0\). Om te weten waar \(f\) stijgt of daalt, moeten we het teken van \(f'(x)\) over intervallen onderzoeken.

Oefening 8

— Redeneren zonder volledig uit te rekenen

G

Een veeltermfunctie \(f\) heeft graad \(6\) en een niet-nul coëfficiënt bij \(x^6\).

Beantwoord zonder een concreet functievoorschrift te kiezen.

Welke graad heeft \(f'\)?

\[ \answer {5} \]

Welke graad heeft \(f''\)?

\[ \answer {4} \]

Kan \(f'\) een constante functie zijn?

Ja Nee

Leg uit waarom je antwoorden noodzakelijk volgen uit de machtsregel.

10
Samengevat

Het afgeleid getal

\[ f'(a) \]

beschrijft de ogenblikkelijke verandering in één punt.

Wanneer we dit voor elke geschikte waarde van \(x\) doen, krijgen we de afgeleide functie

\[ \boxed { f'(x). } \]

Voor veeltermfuncties gebruiken we vooral:

\[ \boxed { (c)'=0 } \]
\[ \boxed { (x^n)'=nx^{n-1} } \]
\[ \boxed { (c f)'=c f' } \]
\[ \boxed { (f\pm g)'=f'\pm g'. } \]

De afgeleide functie kan opnieuw worden afgeleid:

\[ \boxed { f''=(f')'. } \]

Daarbij kun je de drie functies conceptueel lezen als

\[ \boxed { f \longrightarrow \text {grootheid} } \]
\[ \boxed { f' \longrightarrow \text {verandering van de grootheid} } \]
\[ \boxed { f'' \longrightarrow \text {verandering van die verandering}. } \]

11
Wat moet je zeker beheersen?

Na deze opfrissing moet je zelfstandig kunnen uitleggen wat het verschil is tussen \(f'(a)\) en \(f'(x)\), veeltermfuncties correct afleiden met de constante-, machts-, constante-factor- en som- en verschilregel, een tweede afgeleide bepalen en de betekenis van \(f\), \(f'\) en \(f''\) onderscheiden.

Je moet bovendien eenvoudige redeneringen over een afgeleide kunnen controleren. Uit één waarde zoals \(f'(2)<0\) mag je bijvoorbeeld geen besluit trekken over het gedrag van de functie op haar volledige domein.
